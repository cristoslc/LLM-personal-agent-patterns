# Prompt Engineering Guides

This directory contains prompt engineering guides and best practices from major AI companies.

## Best Practices Guides (Markdown)

Each company folder contains a `best-practices.md` file with comprehensive prompt engineering guidelines:

- **Google/best-practices.md** - Based on official Gemini for Google Workspace Prompting Guide 101
- **OpenAI/best-practices.md** - Based on official OpenAI documentation and business guides
- **Anthropic/best-practices.md** - Based on "Building Effective Agents" and official Claude documentation
- **Xai/best-practices.md** - Based on available documentation and general best practices

## Source Materials

### Google
- `gemini-for-google-workspace-prompting-guide-101.pdf` - Official Google guide for prompting Gemini models in Google Workspace
- Source: https://services.google.com/fh/files/misc/gemini-for-google-workspace-prompting-guide-101.pdf

### OpenAI
- `a-practical-guide-to-building-agents.pdf` - Step-by-step guide for developing reliable AI agents
- `ai-in-the-enterprise.pdf` - Guide on leveraging OpenAI models for enterprise business value
- `identifying-and-scaling-ai-use-cases.pdf` - Methodology for finding and scaling impactful AI opportunities
- Source: https://cdn.openai.com/business-guides-and-resources/

### Anthropic
Anthropic's prompt engineering guides are available as web pages rather than direct PDF downloads:
- **Building Effective Agents**: https://www.anthropic.com/engineering/building-effective-agents
- **Prompt Engineering Overview**: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview

The `best-practices.md` file synthesizes content from these official sources.

### Xai
Limited public documentation available. The `best-practices.md` file is based on available resources and general best practices. Check https://docs.x.ai for updates.
