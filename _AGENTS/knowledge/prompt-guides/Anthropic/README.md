# Anthropic Prompt Engineering Guides

Anthropic's prompt engineering guides are available as web pages rather than direct PDF downloads.

## Available Resources

1. **Building Effective Agents**
   - URL: https://www.anthropic.com/engineering/building-effective-agents
   - Description: Guide on creating effective AI agents using Anthropic's Claude models

2. **Prompt Engineering Overview**
   - URL: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
   - Description: Overview of prompt engineering techniques, including when to use prompt engineering vs fine-tuning, role prompts, Chain of Thought (CoT), and XML tags

## Converting to PDF

To save these guides as PDFs:
1. Open the URL in your web browser
2. Use the browser's print function (Ctrl+P / Cmd+P)
3. Select "Save as PDF" as the destination
4. Save the file in this directory

Alternatively, you can use online tools or browser extensions to convert web pages to PDF.
