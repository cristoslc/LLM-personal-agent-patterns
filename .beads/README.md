# Beads - AI-Native Issue Tracking

Welcome to Beads! This repository uses **Beads** for issue tracking - a modern, AI-native tool designed to live directly in your codebase alongside your code.

## What is Beads?

Beads is issue tracking that lives in your repo, making it perfect for AI coding agents and developers who want their issues close to their code. No web UI required - everything works through the CLI and integrates seamlessly with git.

**Learn more:** [github.com/steveyegge/beads](https://github.com/steveyegge/beads)

## Quick Start

### Essential Commands

```bash
# Create new issues
bd create "Add user authentication"

# View all issues
bd list

# View issue details
bd show <issue-id>

# Update issue status
bd update <issue-id> --claim
bd update <issue-id> --status done

# Sync with Dolt remote
bd dolt push
```

### Working with Issues

Issues in Beads are:
- **Git-native**: Stored in `.beads/issues.jsonl` and synced like code
- **AI-friendly**: CLI-first design works perfectly with AI coding agents
- **Branch-aware**: Issues can follow your branch workflow
- **Always in sync**: Auto-syncs with your commits

## Get Started with Beads

Try Beads in your own projects:

```bash
# Install Beads
curl -sSL https://raw.githubusercontent.com/steveyegge/beads/main/scripts/install.sh | bash

# Initialize in your repo
bd init

# Create your first issue
bd create "Try out Beads"
```

## Remediation: Untrack Ephemeral Runtime Files

Beads v0.57.0 ships a `.beads/.gitignore` that does not cover three
runtime files generated by the Dolt server. If your repo committed them
during `bd init`, they will perpetually show as modified in `git status`.

**Affected files** (all machine-specific, change every session):

| File | Content |
|------|---------|
| `dolt-monitor.pid` | Dolt health-check process ID |
| `dolt-server.activity` | Unix timestamp of last server activity |
| `dolt-server.port` | TCP port of the local Dolt SQL server |

**Fix** (run from repo root):

```bash
# 1. Add missing patterns to .beads/.gitignore
cat >> .beads/.gitignore << 'EOF'
dolt-server.port
dolt-server.activity
dolt-monitor.pid
EOF

# 2. Untrack the files (keeps local copies, removes from git)
git rm --cached .beads/dolt-monitor.pid .beads/dolt-server.activity .beads/dolt-server.port 2>/dev/null

# 3. Commit
git commit -m "fix: gitignore ephemeral beads runtime files

dolt-server.port, dolt-server.activity, and dolt-monitor.pid are
machine-specific runtime files that change every session. They were
committed during bd init but should have been ignored.

Adds missing patterns to .beads/.gitignore and untracks the files."
```

> **Note**: If the `git rm --cached` step reports "did not match any files",
> the files were never tracked in your clone -- skip to the `.gitignore`
> patch only.
