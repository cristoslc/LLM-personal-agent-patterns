# Agent Specs

Agent Specs (SPEC-NNN) are behavior contracts — precise enough for an agent to create an implementation plan from, but concise enough to scan in a single pass. Each defines external behavior (inputs, outputs, preconditions, constraints) for a feature scoped to independent delivery.
