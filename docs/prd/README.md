# Product Requirements Documents

This directory tracks PRDs (PRD-NNN) for L3 standalone agents.

## Structure
- `Draft/`: early working specs.
- `Review/`: specs under stakeholder review.
- `Approved/`: accepted specs.
- `Implemented/`: completed specs.
- `Deprecated/`: retired specs.
- `list-prds.md`: lifecycle dashboard index.
