# Research Spikes

This directory tracks research spikes (SPIKE-NNN) for L3 standalone agents.

## Structure
- `Planned/`: queued spikes not yet started.
- `Active/`: spikes currently being executed.
- `Complete/`: finished spikes with findings.
- `list-research.md`: lifecycle dashboard index.
